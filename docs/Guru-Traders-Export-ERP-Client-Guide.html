1. What is Guru Traders Export ERP?

Guru Traders Export ERP is a web-based business system built for an export trading house. It connects the full chain of work in one place:

  • Master data (buyers, products, suppliers, pricing rules)
  • Sales (buyer inquiry → quotation → order confirmation)
  • Procurement (purchase orders → goods inward + QC)
  • Export documentation (packing, invoices, VGM, bank/buyer docs, uploads)
  • Finance trackers (bills, payments, receipts, commission)
  • Reports (outstanding payables / receivables)
  • Administration (users, roles, company letterhead)

The goal is simple: one job moves through the company with the same numbers, same items, and the same documents — without retyping buyer/product data on every desk.

Company letterhead on PDFs (GSTIN, IEC, bank, logo, signatory) comes from Administration → Company Profile.

3. End-to-end business flow

Masters (Category → Order Format → Product → Buyer / Supplier / Agent → Markup) │ ▼ Inquiry → Quotation (PDF / Excel) → Convert to Order Confirmation │ ▼ Order Confirmation (Confirm) ├──────────────────────► Raise Purchase Order(s) [one PO per supplier] │ │ │ ▼ │ Goods Inward + QC Approve │ │ │ ▼ │ Finance trackers (supplier side) │ └──────────────────────► Raise Export Document │ ▼ Packing (cartons / weights) │ ▼ Generate system PDFs │ ▼ Upload / manual checklist │ ▼ Upload eBRC → Shipment Closed │ ▼ Buyer Receipts / Outstanding

You can also create an Order Confirmation as a Direct Buyer Contract (skip full inquiry) when the buyer has already confirmed commercially.

4. Modules explained

4.1 Dashboard

At-a-glance view of inquiries and order confirmations, with simple trends and status distribution.

4.2 Masters — the foundation

Nothing downstream (inquiry, OC, PO, export) works correctly until masters are set up.

Categories

Top-level product groups. Each category can offer the Order Formats that apply to it. Codes like CAT001 are auto-generated.

Order Formats

Defines how the item table looks on Inquiry / OC / PO (columns, units, multi-colour, default delivery & packing text). This is why different product lines can have different grids without changing the software.

Products

Sellable / exportable items under a category. Includes commercial name, name on export document, units (PO vs export), HSN, GST %, price band, fabric measures where needed, barcode, etc.

Buyers

Overseas (or domestic) customers. Stores company details, invoice name, ports, agent & commission, payment terms, incoterm, currency, bank/SWIFT, and carton marking lines used on packing documents.

Suppliers

Vendors from whom goods are purchased. Linked to categories, discount (used in markup costing), agent, bank and contact details.

Jobbers

Same style of master as suppliers, kept as a separate desk for job-work parties.

Agents

Commission intermediaries on Buyer / Supplier / Jobber side. Stores commission % and who pays (we / supplier / buyer).

FOB Values

Simple named FOB value master used as a lookup in commercial work.

Markup

Buyer–supplier margin rules for costing. Conceptually: client price from cost + markup %; our cost after supplier discount; profit is the difference.

4.3 Sales

Inquiries

Buyer ask and internal price working against an Order Format. Status moves through Draft → Price Working → Quote Sent → Confirmed → Converted to OC (or Lost).

  • Quotation is not a separate menu — download PDF / Excel from the Inquiry.
  • Confirmed lines can be Converted to Order Confirmation.

Order Confirmations (OC)

Formal buyer agreement. After confirmation you can:

  • Raise PO for Selected items (procurement)
  • Raise Export Document for Selected items (shipment paperwork)

Statuses: Draft → OC Sent → Confirmed.

4.4 Procurement

Purchase Orders

One supplier’s slice of confirmed OC lines. Tracks Draft → Raised → Partial → Fully Received (Fully Received is driven by goods inward).

Goods Inward

Receive against a PO and record QC on the same screen (ordered / received / passed / rejected). There is no separate Quality menu — QC approve lives here. Statuses: Pending Inspection → Approved (QC Passed) | Rejected.

4.5 Export

Packing

Carton desk for shipments. Carton numbers, net/gross weights, dimensions and lines are maintained on the Export Document; packing list PDFs are generated from there.

Export Documents

One outward consignment to one buyer. Holds logistics (ports, vessel/flight, forwarder, marks, cartons, freight/insurance) and a full documentation checklist from packing lists through eBRC.

Statuses: Draft → In Progress → Closed (when eBRC is uploaded).

Document OCR

Optional AI assist: upload a scan/PDF (CHA checklist, LEO, BL final, Swift, eBRC, etc.) and extract fields into the related checklist row (requires AI key configuration).

4.6 Finance

Finance screens are operational trackers tied to live PO / export data — useful for accounts visibility during operations. They are not a full accounting ledger (no complete voucher book yet).

ScreenWhat it is for
Purchase BillsLinks to generated / uploaded purchase-bill style docs for the shipment
Debit NotesPO-linked adjustment visibility
Supplier PaymentsPayables planning view by PO status
Buyer ReceiptsReceivables view vs Payment Proof / eBRC status on export docs
Agent CommissionCommission preview from PO × agent rates

4.7 Reports

  • Outstanding — Supplier outstanding (from POs) and Buyer outstanding (from Export Documents)
  • Reports hub — counts of POs, export documents, open/closed shipments

4.8 Administration

  • Company Profile — exporter identity printed on documents
  • User Management — create users, activate/deactivate, assign roles
  • Roles — named roles with permission matrix
  • Permissions — registry sync for admins

9. How to use this in a client demo

  1. Show Masters briefly (Category → Format → Product → Buyer/Supplier).
  2. Open an Inquiry, show quotation PDF/Excel.
  3. Open Order Confirmation → Raise PO + Raise Export Document.
  4. Show Goods Inward with QC approve.
  5. Open Export Document → cartons → Generate Documents → View PDFs.
  6. Walk the checklist (what is system-generated vs uploaded).
  7. Open Finance and Outstanding for accounts visibility.
  8. Mention roles: different desks see only their work.
Sample system-generated PDFs for demo shipments can be shared from the Guru-Traders-Demo-PDFs folder (EXP-001 and EXP-002), or viewed live inside Export Documents.

This guide describes the product as delivered for client demonstration. Finance screens are trackers linked to operational data; full ledger accounting can be extended as a later phase if required.
